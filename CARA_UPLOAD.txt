CARA UPLOAD KE GITHUB PAGES

1. Extract ZIP ini.
2. Buat repository GitHub baru.
3. Upload SEMUA file/folder di dalam hasil extract langsung ke ROOT repository.
   Pastikan index.html terlihat langsung di halaman utama repository.
4. Commit changes.
5. Settings > Pages.
6. Source: Deploy from a branch.
7. Branch: main, Folder: / (root).
8. Save dan tunggu deployment selesai.
9. Buka link GitHub Pages lalu Ctrl+F5 jika masih cache versi lama.

PWA:
- Setelah situs dibuka melalui HTTPS GitHub Pages, tombol “Install Aplikasi” akan muncul jika browser mendukung.

AI lokal:
- Pemakaian pertama membutuhkan koneksi internet untuk memuat model MediaPipe.
- Setelah model/browser cache tersedia, pemakaian berikutnya biasanya lebih cepat.
